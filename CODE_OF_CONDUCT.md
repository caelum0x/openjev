# Code of Conduct

This project has adopted the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1, as its code of conduct. The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful, welcoming and constructive; harassment and personal attacks are
not tolerated, in any project space (issues, pull requests, discussions) or when
representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainers by opening a private GitHub
security advisory on this repository (Security tab, "Report a vulnerability") and marking
it as a conduct report, or by contacting a maintainer directly through their GitHub
profile. All reports will be reviewed and handled confidentially. Maintainers may remove,
edit or reject contributions and may temporarily or permanently ban contributors for
behaviour they deem inappropriate, following the enforcement guidelines of the Contributor
Covenant.
